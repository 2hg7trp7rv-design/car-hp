# CBJ 子Guide 最終公開前修正レポート 1

作業日: 2026-06-30
対象: `data/articles/guides/*.json` の子Guide 6本
基準: 親Column `modern-car-custom-regret-reason-column` と `CBJ_記事設計方針_親子構造とモックページ記録_v1`

## 修正方針

- 子記事を専門家向けに深掘りしすぎず、初心者の一つの疑問へ必要十分に答える構造は維持。
- 事実確認が必要な箇所は、断定を弱め、車種差・製品差・装着状態で判断する表現へ修正。
- 親Columnの3軸である「何を変えたいか」「どこまで影響するか」「元に戻せるか」を、各Guideの結論とチェック項目に再接続。
- NALTEC、国土交通省、メーカー保証ページ、主要部品メーカー、業界団体の一次情報・準一次情報に寄せて出典を整理。
- 「警告灯がない＝正常」「車検対応＝必ず通る」「キャンセラー＝純正制御の復元」「少し下げる＝必ず安全」など、誤読されやすい表現を抑制。

## 記事別の主な修正

### aftermarket-air-cleaner-risk-guide

- 純正吸気系の役割を「空気を通す」だけでなく、熱・水・ろ過・騒音・センサー計測まで含めて再説明。
- MAF / MAP / TMAP と燃料噴射・点火・アイドリング・過給制御の関係を、車種差を残した表現へ修正。
- オープンタイプを一律NGにせず、遮熱・外気導入・取り付け位置・センサー前後の形状で判断する表現へ修正。
- OBD数値だけで正常・異常を断定しない注意を強化。

### car-suspension-hard-soft-merit-demerit

- ダンパーの役割を初出で補足。
- バンプタッチを初出で説明し、初心者が本文だけで理解できるように修正。
- 「硬いほど良い」「柔らかいほど快適」という二択を避け、衝撃・収まり・接地感・異音・タイヤ摩耗で判断する結論へ整理。

### electronic-damper-coilover-risk-guide

- 電子制御ダンパーの呼称・制御内容はメーカー/車種で異なることを明記。
- キャンセラーは警告灯や診断エラー対策として使われる場合があるが、純正減衰制御を復元する部品ではないことを強化。
- 車検、保証、整備入庫は別判断であることを再整理。

### adas-lowered-car-aiming-risk-guide

- ADASは運転者の確認を置き換えるものではないことを追記。
- 国土交通省の特定整備制度に合わせ、前方監視カメラやレーダー調整の扱いを本文へ反映。
- エーミング要否を全車共通の下げ幅で断定せず、メーカー整備情報・作業内容・施工後状態で判断する表現へ修正。

### tv-canceller-can-risk-guide

- 運転者の走行中視聴を推奨しないことをリード・本文・結論で明確化。
- CAN対応という表示だけでは、自分の車の年式・型式・純正装備・ソフトウェア状態への適合を保証しないことを追記。
- 取り付け後のソフトウェア更新や診断時の見え方が変わる可能性を追記。

### used-custom-car-check-guide

- カスタム済み中古車を「部品代でお得」と判断しない構造へ修正。
- 後付け部品は装着状態で確認されることを強化。
- 修復歴は骨格に当たる部位の修正・交換歴として扱われること、外装補修だけで必ず修復歴になるわけではないことを補足。
- 純正部品がない場合の戻し費用・説明不能リスクを購入判断へ追加。
