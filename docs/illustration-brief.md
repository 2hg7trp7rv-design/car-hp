# キャラクターの表情差分｜制作指示

学ぶ記事の会話に、表情差分を入れるための指示書です。ChatGPTなどの画像生成に、
そのまま貼って使えるようにしてあります。

## 作るもの

既存の2枚（`public/images/cbj/learning/shuna.webp` / `rina.webp`）と**同じ絵柄・同じ構図**で、
表情だけを変えた差分を作ります。

| 名前 | ファイル名 | 使う場面 |
| --- | --- | --- |
| 通常 | `shuna-normal.webp` / `rina-normal.webp` | ふつうの会話 |
| 驚き | `shuna-surprised.webp` / `rina-surprised.webp` | 「えっ、別なの！？」 |
| 考え中 | `shuna-thinking.webp` / `rina-thinking.webp` | 「うーん……」 |
| 笑顔 | `shuna-happy.webp` / `rina-happy.webp` | 「そういうこと！」 |

合計8枚。既存の2枚は差し替えずに残します（表情の指定がない行で使われます）。

## 守ってほしい条件

サイトでは**直径58〜72pxの丸**に切り抜いて表示します。顔の位置とサイズが1枚ごとに
ずれると、並べたときにガタつきます。次の3つは全カットでそろえてください。

1. **顔の中心の位置**（画面の中央よりやや上）
2. **顔の大きさ**（画像の高さに対する頭の割合）
3. **切り取り方**（胸から上のバストアップ）

そのほかの条件：

- 正方形 **480×480 px**
- 背景は**白一色**（既存2枚と同じ）
- 髪型・髪色・瞳の色・服装は変えない
- 線の太さ、影の付け方、色味も既存に合わせる
- 変えるのは**眉・目・口・手の位置**だけ

## キャラクター設定（既存の2枚から）

**シュナ（生徒役・車が好きだけど知識はこれから）**

- 明るい金髪。頭の上でゆるくまとめ、顔まわりに巻き毛が落ちている
- 茶色の瞳、やわらかい目つき
- ベージュのシャツジャケットを羽織り、中は黒のタンクトップ
- 既存の1枚は「口を開けた笑顔＋頬のそばに指を添えるポーズ」

**莉奈（先生役・詳しい人）**

- 黒髪のポニーテール、前髪あり
- 青い瞳、しっかりした目つき
- 濃紺のつなぎ（胸ポケット2つ）、中は白いTシャツ
- 既存の1枚は「笑顔＋人差し指を立てるポーズ」

## そのまま使えるプロンプト

**先に既存画像（shuna.webp または rina.webp）をアップロードしてから**、次の文を貼ってください。
参照画像なしで作ると、絵柄がそろいません。

### 共通の前置き

```
この画像のキャラクターで、表情違いのバリエーションを作ってください。

絶対に変えないもの：
- 髪型、髪色、瞳の色、服装、絵柄、線の太さ、影の付け方、色味
- 構図（胸から上のバストアップ）、顔の位置と大きさ、白い背景
- 画像サイズは正方形 480×480 px

変えるもの：表情（眉・目・口）と、手の位置だけ
```

### 表情ごとの指示

```
【通常】
口を閉じた、おだやかな微笑み。目は普通に開く。眉はまっすぐ。
手は顔の近くに置かず、自然に下ろす。

【驚き】
目を大きく見開き、眉を上げる。口は小さく開く（「えっ」と言った瞬間）。
片手を軽く上げて、驚いたしぐさにする。

【考え中】
視線をやや斜め上へ。眉を少し下げ、口はへの字に近い小さな閉じ口。
人差し指をあごに添える。

【笑顔】
目を細めた明るい笑顔。口を開けて笑う。
シュナは両手を軽く握って喜ぶしぐさ、莉奈は人差し指を立てる。
```

## 書き出しと置き場所

1. 生成された画像を **PNG** で書き出す（生成直後は白背景のPNGで問題ありません）
2. ファイル名を上の表のとおりにする
3. `public/images/cbj/learning/` に置く
4. WebPへの変換は、リポジトリに入っている sharp で行えます

```sh
node -e "const s=require('sharp');const f=process.argv.slice(1);f.forEach(p=>s(p).resize(480,480).webp({quality:82}).toFile(p.replace(/\.png$/,'.webp')).then(()=>console.log(p)))" public/images/cbj/learning/*.png
```

## サイトで使う

画像を置いたら、会話のデータに `expression` を足すだけで切り替わります。

```json
{ "type": "dialogue", "speaker": "shuna", "expression": "surprised", "text": "えっ、別なの！？" }
```

指定できるのは `normal` / `surprised` / `thinking` / `happy` の4つ。
指定しない行は、これまでどおり既存の1枚を使います。
画像を置く前に `expression` を書くと、`npm test` が「その画像がない」と教えてくれます。

## 図のイラストについて

会話の図（レンチ、トルクカーブ、ターボの羽根など）は、このリポジトリの中で
SVGとして描いています（`components/learning/figures/`）。画像生成は不要で、
文字サイズや配色もページに合わせて変わります。図を足したいときは、
`lib/learning.ts` の `DIAGRAM_KINDS` に名前を足し、同じ名前でコンポーネントを作ります。
