# CBJ COLUMN / GUIDE 記事デザインシステム 実装記録 7

更新日: 2026-06-25

## 対象

- COLUMN: `modern-car-custom-regret-reason-column`
- 表示方式: `cbj-world-v1`
- 役割: 現代車カスタム全体の判断軸を示し、6本の子GUIDEへ送る親コラム

## 今回の変更

### 1. モック再現の既存実装を維持

専用ヒーロー、LESSON表示、会話、記事の流れ、章別配色、図解、表、POINT / CAUTION、戻るボタン、著者、関連記事、FAQ、出典は既存の共通レンダラーを継続利用した。新しい単発ページを増やさず、対象JSONを編集元とする。

### 2. 原稿の事実関係を修正

次の一律表現・固定値を削除した。

- 全ECUが同じCANバスを共有するという説明
- 車高変更量だけでADASエーミング要否を決める説明
- 一般的なFF車として示した架空のアライメント値
- バネレートを純正比±20％とする共通基準
- CE / FCC / VCCIをCAN適合認証とする説明
- 暗電流、バッテリー容量、費用の固定値
- 燃料補正を各気筒単位とする説明
- 水滴付着だけでウォーターハンマーへ直結する説明

車種、制御方式、取り付け状態、メーカー整備情報に基づいて判断する表現へ置き換えた。

### 3. 親COLUMNと子GUIDEの役割を再整理

親COLUMNには以下だけを残した。

- なぜ部品単体で考えると後悔しやすいか
- 吸気、足回り、電装品で共通する確認軸
- 車検、保証、整備入庫、売却まで含めた判断
- 目的、適合、純正保管、施工後確認、記録の順番

スキャナー製品名、価格、車種別数値、詳細な作業方法は削除し、子GUIDEへ分離した。

### 4. JSONの正本化

`prebuild`実行時に圧縮ペイロードから対象JSONを再生成する仕組みを撤去した。

削除対象:

- `scripts/generate-lesson17-current-json.mjs`
- `scripts/payloads/lesson17-current-json-part-*.txt`

今後は `data/articles/columns/modern-car-custom-regret-reason-column.json` が唯一の編集元となる。prebuildで原稿が上書きされない。

### 5. 図解調整

`custom-safe-steps-v2.svg` の5枚目だけ幅が狭かった状態を修正し、5ステップを同じ幅のカードへ統一した。図解のラベルと本文も一致させた。

### 6. 再発防止

記事専用検証へ、不正確な旧表現が対象コラムへ戻った場合にprebuildを失敗させる検査を追加した。

## 根拠資料
