# CBJ Global Page Design Translation

Internal only

## Base principle

Awwwards visual quality must be translated into CBJ page design, not copied

CBJ is an automotive editorial media site

The correct translation is usually restraint, hierarchy, rhythm, and removal of unnecessary UI

## Translate award-site quality into CBJ

### First view

Use one clear subject

Do not let navigation, related links, footer, cards, or decorative labels become the first subject

### Typography

Use typography as structure

Large titles are allowed only when line breaks work naturally in Japanese

Do not split Japanese phrases awkwardly for visual effect

### Layout

Prefer rules, rows, tables, and measured columns before cards

Use cards only for real selection, comparison, or independent item scanning

### Motion

Motion must never be needed to understand the page

Use motion only to support premium pacing

### Footer

Footer is part of the page design

If the footer visually overwhelms a document, form, or profile page, use a lighter footer strategy

### Navigation

Navigation is support UI

If navigation becomes visually stronger than the page subject, reduce it or move it lower on mobile

## CBJ visual defaults

- Paper or black stage backgrounds
- Strong but quiet typography
- Thin rules
- Compact link rows
- Real automotive imagery
- Low component count
- Mobile-first reading order
- No generic SaaS card stacks

## Common corrections

- Replace summary cards with definition lists
- Replace related cards with text links
- Replace outer wrappers with open page rhythm
- Replace large CTA blocks with small link rows
- Replace repeated modules with section rhythm
- Replace decorative labels with useful hierarchy
