# Photo Led Hero

Internal only

## Source lenses

- Photography
- Luxury
- Architecture
- Fullscreen
- Photographic

## Visual signature

- Image creates the first impression
- Text stays quiet
- Overlay contrast is controlled
- Captions are small and editorial
- Desktop and mobile crops are planned separately
- Navigation stays secondary

## Recognition tokens

- Image first
- Sparse type
- Large crop
- Quiet caption
- Strong subject placement
- Controlled overlay
- Mobile crop discipline

## CBJ use

Best for Cars, Heritage, feature lead pages, and strong article hero sections

Use when the vehicle or historical subject deserves first-screen dominance

Translate photography drama into automotive editorial realism

Avoid random image backgrounds, unreadable overlays, and crops that weaken the main subject
