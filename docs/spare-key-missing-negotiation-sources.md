## 編集判断と境界

- 「納車までに使えるキーを2本」「費用・納期・作業を文書に残す」「1本ずつの作動確認」は編集部としての購入相談・確認の提案。すべての中古車で2本の付属が保証されるとは書かない。
- 値引きが必ずできるという保証、販売店の法的義務、一律の費用・工数・納期は記載しない。
- 電子的なキーの登録と、内蔵された機械式の鍵を区別する。紛失キーの登録抹消を実行していないのに、追加購入だけで紛失分が使えなくなったとは書かない。
- 同じ形の中古キーが必ず使えるとも、すべて使えないとも断定しない。対象車への登録可否・持ち込み可否を依頼先へ確認する内容にとどめる。
- 残っているキー、車種、年式、装備により扱いが異なるため、メーカー固有例には年式と車種を付記する。
- 画像は設定しない。既存の距離計・カスタム画像をキーの説明に流用しない。OGPはページ側のサイト共通fallbackに委ねる。記事一覧は別コンポーネントの自動画像fallbackがあるため、親担当へ表示上の課題として共有済み。
- 記事の原稿に存在する関連記事は `/guide/used-custom-car-check-guide` のみ。カスタム中古車を検討する人向けと前置きし、スペアキー問題の代替記事と誤認させない。
