# CBJ SNS / Landing Visual Translation

Internal only

## Role

SNS and landing visuals must create a strong first impression and move the viewer to one next action

They should not become decorative templates

## Use

- One clear hook
- One subject per screen
- Strong first-view composition
- Large readable type
- Controlled image or illustration role
- Simple CTA
- Platform-specific size discipline

## Avoid

- Too many messages in one visual
- Generic carousel templates
- Dense captions inside the image
- Weak first slide
- Multiple CTAs
- Decorative UI that hides the point

## Awwwards translation

Use visual confidence, contrast, and pacing

Do not copy experimental navigation or complex web interactions into SNS graphics

## CBJ sizes

- Reels and story-style vertical: 1080 x 1920
- Carousel feed: 1080 x 1350

## Check before approval

- Is the first screen strong enough without explanation
- Is it readable on smartphone
- Is the subject obvious
- Would the user save, swipe, or tap
